# Math behind ordinal logit regression 

The ordinal logit regression model is a type of regression used for predicting an ordinal dependent variable based on one or more independent variables. The model assumes that the relationship between the independent variables and the log-odds of the dependent variable is linear.

Its used when the dependent variable is ordinal, meaning that it has a natural order but the distances between the levels are not necessarily equal. For example, a survey question asking respondents to rate their satisfaction on a scale of 1 to 5 would be an ordinal variable.
